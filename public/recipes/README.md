# レシピ写真の置き場

完成写真をこのディレクトリに置き、`lib/recipes.ts` の該当レシピに `photo` を追加すると、
詳細ページ・一覧カード・OGP・構造化データの `image` に自動で反映される。

## 手順

1. 画像をこのディレクトリに置く。ファイル名はレシピの `id` に合わせる（例: `renji-mabo-nasu.jpg`）
2. `lib/recipes.ts` の該当レシピに追記する:

```ts
photo: {
  src: "/recipes/renji-mabo-nasu.jpg",
  alt: "とろりとしたなすと肉味噌を器に盛った麻婆なす",
  width: 1600,
  height: 900,
},
```

`photo` を書かないレシピは、`next/og` が生成するテキストカードに自動でフォールバックする。
写真がある品と無い品が混在していても表示は崩れない。

## 画像の要件

| | |
|---|---|
| 形式 | JPEG または WebP（Google の Recipe 構造化データは SVG 非対応） |
| 推奨サイズ | 長辺 1600px 程度。`width` / `height` は実寸を書く |
| アスペクト比 | 16:9 を基本にする。一覧カードは `object-cover` で 16:9 に切るため、被写体は中央寄せが安全 |
| ファイルサイズ | 1枚 300KB 以下が目安（`next/image` が配信時に最適化するので原寸は大きくてよい） |

`width` / `height` は実際の画素数と一致させること。ずれるとレイアウトシフトの原因になる。

## alt テキスト

料理が分かる説明を書く。「料理の写真」「イメージ」のような無内容な文言は、
スクリーンリーダー利用者にも検索エンジンにも無価値なので避ける。

## ライセンス

自分で撮影した写真なら `credit` は不要。

配布素材を使う場合は、**その素材のライセンスが商用利用を許可しているか必ず確認**したうえで、
表示義務があるときだけ `credit` を設定する:

```ts
credit: { name: "撮影者名 / サイト名", url: "https://..." },
```

`credit` を設定すると写真の下に出典が表示され、リンクには `nofollow` が付く。

## 注意

料理写真は「そのレシピの手順で実際に作った結果」であることが望ましい。
別物の写真を載せると、読者の期待と実物がずれるだけでなく、
Google の構造化データのガイドライン上も推奨されない。
